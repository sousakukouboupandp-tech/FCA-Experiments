## 0. この版の位置づけ

- **段階0は学習させない。** 世界の遷移を厳密に書き、solver で各目的の最適方策を解いて比べる。FCA の機構（Pain Memory・Narrative・iNEC・根）は入れない

## 1. 表1 — World_1-G の世界の物理

### 1-1. 時間
- 1歩（primitive step）が世界の時計の単位。寿命 1000歩
- 行動の最中も、世界の時計は毎歩進む（体力の消耗・傷の治癒・大物の回復はすべて毎歩）

### 1-2. 意思決定
- **decision は時間を使う MODE ではなく、意思決定の境界（decision epoch）**
- 歩の始めに選べる状態なら、その場で行動を選び、**同じ歩を、選んだ行動の1歩目として実行する**
- 行動は次の3つ：草を食べる／小物を探す／大物を探す（大物が1頭以上いるときだけ）
- **始めた行動は終わるまで中断できない**（探索・追跡・戦闘すべて。precalc_v3 の暗黙の前提を写したもの）

### 1-3. 体力（内部表現は ×20 の整数。近似ではなく等価）
| 量 | 原本の値 | 内部値 |
|---|---|---|
| 上限 | 100 | 2000 |
| 基礎消耗 | 1.0/歩 | 20/歩 |
| 傷1つの追加消耗 | 0.25/歩 | 5/歩 |
| 草の摂取 | 0.7/歩 | 14 |
| 小物の栄養 | 30 | 600 |
| 大物の栄養 | 90 | 1800 |

- その歩の消耗 = 20 + 5 × W_t（**歩の始めの傷の数**で決まる）
- 上限を超えた分は捨てる（貯蔵口座は作らない。7/30 裁定で第二幕へ送ったまま）
- **その歩の摂取と消耗をすべて反映してから、飢え死を判定する**（E_{t+1} ≤ 0 で飢え死）

### 1-4. 草
- 一口ずつ。1歩の行動。食べたあと、次の歩でまた選び直せる（始祖の裁定：ア）
- 1歩の正味 = −20 + 14 = −6（原本換算 −0.3/歩）

### 1-5. 小物
- 残り具合 N_S は 12 から始まり、捕まえるたびに1つ減る。**補充も繁殖もない**
- **1 で止まる**：N_S = 1 で捕まえても 1 のまま（N'_S = max(1, N_S − 1)）
- **N_S = 1 は文字どおりの「最後の1匹」ではなく、絶滅しない希少な残存層を表す**（N_S は個体数というより、見つけやすさの段階）
- 探索：毎歩、遭遇確率 N_S ÷ 24（幾何分布。平均 24 ÷ N_S 歩）。**遭遇した歩も探索に数える**
- 遭遇したら追跡4歩。4歩目に捕獲確率 0.7
- 捕獲に成功した歩だけ、摂取 600 と N_S の減少が起きる。失敗では N_S は減らない
- 期待値での位置づけ（World_1-ref の式）：残り2で +0.31/歩、残り1で −0.25/歩（草 −0.30/歩よりわずかにまし。それだけでは生きていけない）
- 探索時間を幾何分布にしたのは、原本に平均値しかないため。固定時間は感度分析として残す

### 1-6. 大物
- 頭数 N_L は 3 から始まり、0〜3 をとる。仕留めるたびに1頭減る
- **N_L = 0 は吸収状態（絶滅）。その一生では戻らない**
- N_L = 1 または 2 のとき、毎歩 1/250 で1頭戻る（**不足数によらず一段ずつ**。平均250歩で1頭。幾何分布は頭数だけで Markov 性を保つための簡略化）
- N_L = 3 では戻らない
- 探索：毎歩、遭遇確率 1 ÷ T_L(N_L)。T_L(N) = 8 × (3 ÷ N)^k。**基準 k = 1.5**
  - N=3：8.0歩／N=2：約14.7歩／N=1：約41.6歩（3頭時の約5.2倍）
  - k = 1.5 は、始祖の「最後の1頭は3頭時の5倍以上」を満たす最小の指数（ln5 ÷ ln3 ≈ 1.465）に近い値
  - **k = 2.0（N=2：18歩／N=1：72歩）を感度分析として事前登録**
- 探索中に頭数が戻れば、**次の歩から**遭遇確率が変わる

### 1-7. 大物との戦闘（World_1-ref と等価な復元モデル）
- 1ラウンド = 1歩。毎ラウンド、**排他的な4つの結果から1つ**を1回だけ抽選する

| 結果 | 確率 | その後 |
|---|---|---|
| 仕留める | 0.25 | 摂取 1800、N_L − 1、decision へ |
| 急所に被弾して死ぬ | 0.04 | 死（体力に関係なく終端） |
| 被弾して傷1つ | 0.36 | W + 1、戦闘継続 |
| 空振り | 0.35 | 戦闘継続 |

- **仕留めたラウンドには被弾しない**（原本に明記はない。原本の式と数字を再現する最も単純な読み）
- この復元モデルで 200万回試行：死亡率 0.1379、平均ラウンド 3.44、期待負傷 1.24。原本（13.8%・3.45・1.24）と一致（2026/9/18）
- 13.8% は別に足さない。ラウンドモデルから結果として出る（二重計上しない）

### 1-8. 傷
- 歩の始めにある W_t 個の傷が、**それぞれ独立に 1/150 で治る**（1歩で治る数は二項分布）
- **その歩で新しく負った傷は、次の歩から治癒の対象**
- 世界の物理としての傷の数の上限は置かない（寿命1000歩で有限）
- 数値計算では W ≥ K をあふれ状態にまとめ、そこに入る確率を測る。無視できなければ K を増やす（K は結果に合わせて決めない）
- 幾何分布にしたことで、有限の寿命のもとでの傷の期待支払いが World_1-ref から変わる（§5-B）

### 1-9. 終端
- 飢え死：その歩の全収支を反映した後、E_{t+1} ≤ 0
- 急所死：戦闘の抽選結果が「急所」なら、体力に関係なく死
- 天寿：**1000歩目の遷移を生き抜いた場合だけ**天寿。1000歩目で死んだら天寿ではない
- 行動の途中でも、上の3つはそのまま適用する

### 1-10. 同じ歩の中の更新規約
- その歩の始めの状態 S_t を読み、その歩の出来事をすべて抽選し、**まとめて S_{t+1} に反映する**（同期更新）
- **同じ歩の中の別系統の確率の出来事（行動の結果・傷の治癒・大物の回復）は、S_t のもとで互いに独立に抽選する**。相関を入れる根拠は現在ないので、入れない
- 大物の遭遇確率は N_{L,t} から計算する。同じ歩の回復が効くのは次の歩から
- **競合規則**：N_L = 1 の歩で「仕留める」と「1頭戻る」が同時に当たったら、**仕留めによる絶滅を優先**し N'_L = 0 とする
  - それ以外は N'_L = min(3, N_L + 回復 − 仕留め)

- 状態数は仮定しない。**初期状態から到達可能な decision 状態を前向きに列挙して実測する**

## 5. 再現仕様（Monte Carlo・単体テスト）

### A-1. 数値の不変量（一致しなければ実装のバグを疑う）
- 戦闘単体：死亡率 0.04/0.29 ≈ 13.79%、平均ラウンド 1/0.29 ≈ 3.448、**負傷の発生回数** 0.36/0.29 ≈ 1.241
  - 「戦闘終了時に残っている新しい傷の数」は、戦闘中の治癒があるので別の量として測る。これを 1.241 と比べない
- 草だけ：**334歩目に飢え死**（2000 − 6×333 = 2 > 0、2000 − 6×334 = −4 ≤ 0）
- 小物の単体テスト（傷0固定・N_S固定・寿命打ち切りなし・途中の飢え死なし）：探索の平均 24/N_S 歩、1回あたりの正味は World_1-ref の値に収束
- 大物探索の単体テスト（N_L固定・回復なし）：探索の平均 T_L(N_L)
- 「/歩」の正味は、1回ごとの比の平均ではなく、（総摂取 − 総消耗）÷ 総歩数で測る

### A-2. 構造の不変量（毎回確認する性質）
- 1 ≤ N_S ≤ 12、0 ≤ N_L ≤ 3、0 ≤ E ≤ 2000（終端を除く）
- N_L = 0 なら N'_L = 0
- t' = t + 1
- decision 境界以外では行動を選べない
- 小物の捕獲失敗では N_S が減らない
- 急所死は他の値にかかわらず終端
- N_L = 0 では大物探索を選べない
- 新しい傷はその歩では治癒判定を受けない

### B. 宣言した変更の指紋（変わることが正しいもの）
- **傷の治癒を幾何分布にしたことによる、残寿命別の傷の期待支払い**（1回の大物狩り、期待負傷 1.241 × 0.25/歩 × 期待支払い歩数）

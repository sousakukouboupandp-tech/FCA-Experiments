# 有限確率世界における三目的比較実験の設計仕様（監査用・結果を見る前に凍結）

以下は、結果を見る前に凍結した有限確率世界と比較実験の設計である。
著者の意図を擁護せず、次を列挙してほしい。

- 数学的不整合
- 未定義の挙動
- 交絡
- 恣意的な自由度
- 近似による系統誤差
- 実装と測定の不一致
- 結果の解釈を歪める可能性のある箇所

改善提案は、**結果を見る前に修正すべきもの**と、**結果を見た後でもよいもの**に分けてほしい。

## 1. 世界の物理

一個体が寿命1000歩の一生を生きる。1歩が時間の単位。

### 1-1. 体力（内部表現は整数。原本値の×20）
- 上限 2000
- 毎歩の消耗 = 20 + 5 × W（W は歩の始めの傷の数）
- 上限を超えた摂取は捨てる
- **その歩の摂取と消耗をすべて反映してから飢え死を判定する**（E ≤ 0 で飢え死）

### 1-2. 意思決定
- decision は時間を使わない境界。歩の始めに行動を選び、**同じ歩をその行動の1歩目として実行する**
- 行動は3つ：草を食べる／小物を探す／大物を探す（大物が1頭以上のときだけ）
- **始めた行動は終わるまで中断できない**（探索・追跡・戦闘）

### 1-3. 草
1歩の行動。摂取 14。正味 −6/歩。食べたら次の歩でまた選べる。

### 1-4. 小物
- 残り具合 N_S は 12 から始まり、捕獲のたびに1減る。**補充も繁殖もない**
- **1 で止まる**（N'_S = max(1, N_S − 1)）。N_S=1 は個体数ではなく「絶滅しない希少な残存層」を表す
- 探索：毎歩の遭遇確率 N_S / 24（幾何分布。平均 24/N_S 歩）。**遭遇した歩も探索に数える**
- 遭遇したら追跡4歩。4歩目に捕獲確率 0.7。成功した歩だけ摂取 600 と N_S の減少

### 1-5. 大物
- 頭数 N_L は 3 から始まり 0〜3。仕留めるたびに1減る
- **N_L = 0 は吸収状態（絶滅）。その一生では戻らない**
- N_L が 1 または 2 のとき、毎歩 1/250 で1頭戻る（不足数によらず一段ずつ）
- 探索：毎歩の遭遇確率 1 / T_L(N_L)、T_L(N) = 8 × (3/N)^1.5
  （N=3: 8.0歩／N=2: 約14.7歩／N=1: 約41.6歩）
  - **k = 2.0（N=2: 18歩／N=1: 72歩）を感度分析として事前登録**
- 探索中に頭数が戻れば、次の歩から遭遇確率が変わる

### 1-6. 大物との戦闘
1ラウンド = 1歩。毎ラウンド、排他的な4つの結果から1つを1回だけ抽選する。

| 結果 | 確率 | その後 |
|---|---|---|
| 仕留める | 0.25 | 摂取 1800、N_L − 1、decision へ |
| 急所に被弾して死ぬ | 0.04 | 死（体力に関係なく終端） |
| 被弾して傷1つ | 0.36 | W + 1、戦闘継続 |
| 空振り | 0.35 | 戦闘継続 |

このモデルから出る量：死亡率 0.04/0.29 ≈ 13.79%、平均ラウンド 1/0.29 ≈ 3.448、
1戦あたりの負傷発生回数 0.36/0.29 ≈ 1.241。

### 1-7. 傷
- 歩の始めにある W 個が、**それぞれ独立に 1/150 で治る**（1歩に治る数は Binomial(W, 1/150)）
- **その歩で新しく負った傷は、次の歩から治癒の対象**
- 世界の物理としての上限は置かない

### 1-8. 終端
- 飢え死：その歩の全収支を反映した後、E ≤ 0
- 急所死：戦闘の抽選が「急所」なら、体力に関係なく死
- 天寿：**1000歩目の遷移を生き抜いた場合だけ**天寿
- 終端状態にも体力の値は保持される（**負の値になりうる。0 に切らない**）

### 1-9. 同じ歩の中の規約
- その歩の始めの状態 S_t を読み、その歩の出来事をすべて抽選し、まとめて S_{t+1} に反映（同期更新）
- **同じ歩の別系統の出来事（行動の結果・傷の治癒・大物の回復）は、S_t のもとで互いに独立に抽選する**
- 大物の遭遇確率は N_{L,t} から計算する。同じ歩の回復が効くのは次の歩から
- **競合規則：N_L = 1 の歩で「仕留める」と「1頭戻る」が同時に当たったら、絶滅を優先して N'_L = 0**

### 1-10. 初期状態
体力 2000、傷 0、N_S = 12、N_L = 3、t = 0

### 1-11. 行動の所要歩数の上限
τ_max = 100（消耗の下限20と体力上限2000、摂取が decision 境界の歩にしか起きないことから）。
状態ごとの上限は τ ≤ ceil(E_t / 20)。

## 2. 比較する三つの目的

学習させない。各目的の**最適方策を厳密に解いて**比べる。

### D0：期待寿命の最大化
- 報酬：その行動中に実際に生きた歩数（合計が寿命に一致）
- γ = 1（有限寿命なので発散しない）
- 寿命の定義：終端に達するまでに実行した1歩遷移の数（最大1000）。**死んだ歩も1歩として数える**
  - 334歩目に飢え死 → 寿命334
  - 1000歩目に急所死 → 寿命1000。ただし天寿ではない
  - 1000歩目を生き抜く → 寿命1000かつ天寿

### D_S-exact：天寿到達確率の最大化
- 目的：P(1000歩目の遷移を生き抜く)。有限時間の後ろ向き帰納で直接解く
- γ = 1。報酬の形には落とさない（V_t(s) = 生存確率）

### D1a：恒常性の維持（Keramati & Gutkin 2014, eLife 3:e04811 の素の形）
- 恒常性空間は1次元：H_t = (E_t)。傷は H に入れない
- 駆動：**D(E) = |E_set − E|^q**（原論文 D = (Σ|h*−h|^n)^(1/m) の1次元版。**q = n/m だけが効く**）
- 報酬：**r_t = D(E_t) − D(E_{t+1})**
- γ < 1（原論文は γ=1 では軌跡の途中が相殺されると明示）
- **死に特別な罰を足さない。終端より先に報酬を足さない**
- **死の歩も1歩の遷移として r_t を発生させる。E_{t+1} は終端に保持される値（負になりうる）を使う**

**事前に計算した値：死の歩の報酬**

急所死の歩（E 1900 → 1880）の r：

| E_set | q=4/3 | q=3/2 | q=2 |
|---|---|---|---|
| 2000 | −127.7 | −314.5 | −4400 |
| 1600 | +176.5 | +510.9 | +11600 |
| 1400 | +210.2 | +664.1 | +19600 |
| 1200 | +235.6 | +788.0 | +27600 |

飢え死の歩（E 20 → 0）の r：

| E_set | q=4/3 | q=3/2 | q=2 |
|---|---|---|---|
| 2000 | −335.4 | −1338.3 | −79600 |
| 1600 | −311.2 | −1196.2 | −63600 |
| 1400 | −297.6 | −1118.5 | −55600 |
| 1200 | −282.6 | −1034.9 | −47600 |

**E_set ≤ 1600 では急所死の歩に正の報酬が出る。これを修理しない。**

**感度分析の軸（すべて事前固定）**
- q ∈ {4/3, 3/2, 2}（代表の (m,n) = (3,4)／(2,3)／(2,4)）。**基準を置かず3条件すべて報告する**
- E_set ∈ {2000, 1600, 1400, 1200}。**2000 は上限と設定点が一致する境界条件**と明記
- γ：有効視野 1/(1−γ) ∈ {50, 150, 500, 1000}
- 合計 **48条件**

**使わないもの**：Yoshida 2016 型の生存確率目的。原定式化が時点生存確率 P > 0 を仮定に置いており、この世界には確定死があるため。

**原論文の等価定理について**：reward 最大化＝偏差最小化（γ<1）の証明は「初期状態から始まり設定点で終わる軌跡」に限定されている。死・1000歩・絶滅を含むこの世界の全軌跡について「等価」とは主張しない。

### 同点の扱い
- `optimal_set`（同点の行動すべて）と `selected_for_execution`（固定順序：草→小物→大物）を両方保存
- 判定：|Q_a − Q_b| ≤ atol + rtol · max(1, |Q_a|, |Q_b|)、atol = 1e-9、rtol = 1e-12

## 3. 測定規則

- 方策一致率：全状態／D0 の一生で重み付け／比較相手の一生で重み付け／両者の平均
- 到達する状態の分布そのものの差
- 期待寿命、天寿到達率、死因の分布（飢え・急所・天寿）
- 絶滅（N_L=0）が起きた一生の割合と、起きた時刻の分布
- 小物が下限に達した時刻の分布、傷の数の分布とあふれ確率
- 行動の占有率と行動エントロピー（**記述統計としてのみ。高い方が良いとはしない**）
- 最適行動の切り替わり境界を実際に通る回数
- 大物1頭の状態での、大物探索の選択率
- **迷いの三分類**（状態ごとに Q1, Q2, Q3 を取る）
  - 無差別：Q1 − Q3 が小さい
  - 選択競合：Q1 − Q3 は大きいが Q1 − Q2 が小さい
  - risk-divergent near-tie：選択競合であり、かつ**上位2行動の危険度の差が大きい**
  - 危険度 = **P(次の decision 境界に戻る前に死ぬ | s, a)**。探索中・追跡中・戦闘中の飢え死、傷の消耗の影響、急所死を含む。**天寿到達は危険死に数えない**
  - 正規化した差 (Q1−Q2)/(Q1−Q3+δ) と自然単位の差を両方保存。**ε で二値化する前の分布を保存する（閾値を結果の後から選ばない）**
- **全条件の結果を報告する（きれいな条件だけ出さない）**
- 解析の順番を事前に固定：(1) D0 の方策地図と行動領域の数 →(2) D_S-exact との比較 →(3) D1a との比較 →(4) 迷いの三分類 →(5) 感度分析

## 4. solver の仕様

### 4-1. 表現
- 正本は**1歩単位の MDP**。macro（semi-MDP）にはまとめない
- 状態は固定 index の dense 表現
- MODE は8種類（decision / search_small / chase_1..4 / search_large / combat）。
  **grass は存在しない**（decision の歩で草を食べ、その歩の終わりに decision へ戻るため）
- index：`i = ((((m*2001 + e)*11 + w)*12 + (n_small−1))*4 + n_large)`
  - 合計 8 × 2001 × 11 × 12 × 4 = **8,452,224**
  - decision 状態のみの直積は **1,056,528**
  - **w 軸の11枠目（index 10）は「W ≥ 10 のあふれ」であって「ちょうど10」ではない**
  - 負の体力は終端にしか現れないので index に含めない

### 4-2. 計算
- 後ろ向き帰納の価値は current / next の2層（primitive なら常に t → t+1）
- **方策は decision 状態についてのみ全時刻を保持**（1状態1バイト、0.98GB）
- 後ろ向きで解いたあと、**前向きにもう一度流して占有率を出す（2パス）**
- **方策だけでは測定規則を復元できない**ので、後ろ向きの途中で派生量を保存する

| 保存するもの | 型 | 1条件あたり |
|---|---|---|
| 方策 | 1バイト | 0.98 GB |
| optimal_set | 1バイト | 0.98 GB |
| 上位2行動の価値の差 | float16 | 1.97 GB |
| 行動価値の開き（1位−3位） | float16 | 1.97 GB |
| 上位2行動の危険度の差 | float16 | 1.97 GB |
| 合計 | | **約7.9 GB** |

- **48条件を全部保存すると約661GB**になるので、1条件ずつ解き、集計後は**要約だけ**残す
- 数値は float64。同点判定は上記の絶対＋相対

### 4-3. 検証
- 縮小世界（寿命20歩・体力上限200・小物3・大物2・傷上限3）で全状態を列挙し、
  **価値だけでなく全 decision 状態・全合法行動の Q まで一致**することを確認する
- 終端の負の体力を使うことの回帰テスト：E=2 → 消耗20 → 終端 E=−18 で、
  D1a の報酬が E=0 ではなく E=−18 を使って計算されること

### 4-4. 実行の停止条件（事前登録）
- 状態総数 2000万／実行30分／**プロセス自身の RSS 8GB**
- RSS は外側の watchdog（親プロセス）でも監視する

## 5. 既知の近似の一覧

**世界の物理を、期待値モデルから確率モデルに翻訳したときに宣言した変更**
1. 傷の治癒：「ちょうど150歩で治る」→「各傷が独立に 1/150（幾何分布、平均150歩）」
   - 有限の寿命のもとで、傷の期待支払いが変わる（残寿命800で 46.6 → 46.3、400で 46.6 → 43.3、200で 46.6 → 34.3）
   - **元の位置に戻すための再調整はしない**
2. 探索時間：平均値のみ → 幾何分布（同じ平均）。固定時間版を感度分析として事前登録
3. 大物の回復：「ゆっくり戻る（平均250歩）」→ 幾何分布（1/250）
4. 大物戦：期待値の式 → 排他的な4結果のラウンドモデル（元の数値を再現することを確認済み）

**solver の近似**
5. **傷のあふれ K=10**：W ≥ K を代表値 K として扱う。これは3方向にずれる
   - 1歩の消耗：真 W=12 で 80 → 代表 70（**−12.5%**）
   - 1歩の期待治癒数：真 0.08000 → 代表 0.06667（**−16.7%**）
   - **あふれからの脱出が早い**：真 W=12 → 1個治癒 → W=11（まだあふれ）／代表 W=10 → W=9（脱出）
   - K = 10 → 12 → 15 で、あふれの質量・初期状態の価値・optimal_set・主要な不一致が収束することを確認する

**近似ではないもの**（明記）：確率の打ち切り・標本化・粗視化・状態の集約は一切入れていない。

## 6. この世界の来歴（監査の判断材料として）

この世界の数値は、**期待値モデルの上で「小物と大物の選択が拮抗する帯」が現れるように調整されたもの**である。
3回の失敗のあと、4回目で拮抗が得られた。したがってこの世界は**中立に生成された世界ではなく、意図的に拮抗を仕込んだ校正世界**である。
ここから一般性は主張しない。
